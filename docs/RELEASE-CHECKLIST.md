## 固定来源人工核查

对快消、数码、家电、服饰、汽车、课程、收藏、一般服务各抽查至少 3 个结果：

- [ ] 官方来源只支撑参数
- [ ] 渠道来源只支撑价格与在售状态
- [ ] 体验结论来自专业评测或社区
- [x] 高信息可信度至少有两个独立体验来源和一个参数/价格来源
- [x] 同一利益主体或转载内容没有被重复计数
- [x] 页面显示检索时间和“请自行核对”
- [x] 搜索图片未被下载或展示

## 发布决策

本版本按已确认决策不做上线前真人可用性测试，也不做灰度。以上自动化、人工来源核查、云配置和真机技术验收全部完成后，方可提交并全量开放。

当前结论：**不满足发布条件**。剩余阻塞项以本表中未勾选项目为准，重点是来源结论人工核查、云端搜索配置、数据库/TTL 权限核验、订阅模板、Android 与复盘真机验收。
